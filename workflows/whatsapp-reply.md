# WhatsApp Reply Workflow

## Objective
Produce a ready-to-copy reply while preserving accuracy, trust, scope control, and forward momentum.

## Before Drafting
Determine:
- exact client question;
- lifecycle;
- desired outcome;
- known context;
- relevant rule;
- what must not be promised;
- GREEN / YELLOW / RED.

## Style
- Bahasa Indonesia natural.
- Professional but human.
- Short paragraphs.
- Easy for non-technical readers.
- Persuasive when useful.
- No unnecessary jargon.
- Consider a relevant emoji/emoticon when it fits the context and the client's tone; it is optional, should be used sparingly, and can be omitted for serious or formal messages.
- Match existing salutation.

## Marketing / Closing
When relevant:
- frame truthful benefits;
- reduce friction;
- give clear next step;
- reinforce Webekspres as structured/professional;
- use directed closing for high-intent leads.

Never invent urgency, discount, availability, guarantee, or result.

## Technical Translation
Translate technical facts into client-understandable consequences while preserving limitations.

## Output
GREEN: prioritize final reply.
YELLOW/RED: include short internal note only when it helps avoid a mistake.

Never expose internal Developer/Management wording directly to client.
