# Customer Service Routing

Classify the current work into one or more:
- LEAD / SALES
- QUALIFICATION
- PACKAGE / PRICE
- PROPOSAL / FOLLOW-UP
- CLOSING
- PAYMENT / ADMINISTRATION
- ONBOARDING
- PROJECT PROGRESS
- REQUIREMENT
- TECHNICAL
- REVISION / CHANGE REQUEST
- COMPLAINT / SUPPORT
- TESTING / UAT
- TRAINING
- HANDOVER
- AFTER SALES
- RENEWAL
- LEGAL / DOCUMENT
- INTERNAL COORDINATION

The user does not need to state the category.

## Lifecycle Vocabulary
Primary lifecycle:
`LEAD`, `QUALIFICATION`, `PROPOSAL`, `FOLLOW_UP`, `CLOSING`, `PAYMENT`, `ONBOARDING`, `QUEUE`, `DEVELOPMENT`, `REVISION`, `TESTING`, `TRAINING`, `HANDOVER`, `COMPLETED`, `AFTER_SALES`, `RENEWAL`, `CANCELLED`.

Operational status:
`ACTIVE`, `WAITING_CLIENT`, `WAITING_DEVELOPER`, `WAITING_MANAGEMENT`, `READY_TO_REPLY`, `RESOLVED`.

## Routing Questions
Determine internally:
1. Who is speaking?
2. What does the client actually need?
3. What lifecycle stage is this?
4. What source is authoritative?
5. Does CS have authority to answer?
6. What is the next useful action?
7. Does this require a permanent artifact?
